# ☕ Rappokopi Website

Website profil dan katalog menu interaktif resmi untuk **Rappokopi** — kedai kopi lokal yang menyajikan varian kopi susu aren, non-kopi, seri creamy, americano, matcha, serta paket promo menarik.

---

## 🚀 Fitur Utama
* **Navigasi Single-Page Responsif:** Berpindah antar halaman (Beranda, Menu, Promo, Lokasi) dengan mulus tanpa memuat ulang halaman penuh.
* **Katalog Menu Interaktif:** Dilengkapi fitur pencarian (*search*) secara *real-time* serta filter kategori (Kopi & Nonkopi).
* **Modal Detail Produk:** Menampilkan informasi lengkap, deskripsi, harga, serta ketentuan promo saat menu atau paket dipilih.
* **Informasi Lokasi & Integrasi Peta:** Dilengkapi detail alamat kedai, jam operasional, tautan Google Maps, serta tombol langsung menuju Direct Message (DM) Instagram.
* **Desain Estetik & Ramah Pengguna:** Menggunakan palet warna hangat khas kedai kopi serta tipografi modern (*Plus Jakarta Sans*).

---

## 🛠️ Teknologi yang Digunakan
* **HTML5** & **CSS3** (dengan variabel kustom dan *Media Queries* untuk tampilan HP)
* **Bootstrap 5.3.3** (kerangka kerja UI dan komponen *grid*)
* **jQuery 3.7.1** (untuk manipulasi data menu, pencarian, dan modal interaktif)
* **AOS (Animate On Scroll)** (untuk efek transisi animasi saat halaman digulir)
* **Google Fonts** (*Plus Jakarta Sans*)
